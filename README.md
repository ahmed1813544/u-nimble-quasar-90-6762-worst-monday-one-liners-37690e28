Entry for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on make.fun.

`main.py` (Python 3.13, standard library only) writes exactly one funny line —
a joke about an AI agent's worst Monday, at most 140 characters — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
It is deterministic: every run writes byte-identical output.

Run it:

```sh
python3 main.py
```
